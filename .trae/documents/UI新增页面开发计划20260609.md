# 音瓶 - UI 新增页面开发计划

## 1. 项目现状分析

### 1.1 当前架构

- **单页应用**：仅一个路由 `/`，所有功能集中在 `Home.tsx` 页面
- **布局结构**：左侧面板（搜索/收藏/歌单/历史）+ 右侧主区域（唱片/歌词 + 控制栏）
- **状态管理**：Zustand 单 Store（`playerStore.ts`），管理所有播放器状态
- **技术栈**：React 18 + TypeScript + Vite + TailwindCSS + Zustand + react-router-dom

### 1.2 当前功能模块

| 模块 | 位置 | 现状 |
|------|------|------|
| 搜索 | Home.tsx（主页搜索区） | ✅ 功能完整 |
| 收藏 | Profile.tsx（个人页收藏Tab） | ✅ 功能完整 |
| 歌单 | Profile.tsx（个人页歌单Tab） | ✅ 功能完整（新建/删除/重命名/添加歌曲） |

### 1.3 痛点与问题

1. **playerStore 过于庞大**：1451行代码，包含播放、搜索、收藏、历史、推荐、漫游、OCR、深色模式、歌单管理等所有逻辑，应拆分为多个独立 store
2. **SongRow 组件重复**：PlaylistPanel.tsx、PlaylistDetail.tsx、SongDetail.tsx 各自定义了不同版本的 SongRow，未统一抽取
3. **MiniPlayer 双重实现**：MiniPlayer.tsx 和 Layout 中的 GlobalMiniPlayer 功能重叠
4. **缺少设置独立 Store**：设置状态全部混在 playerStore 中，未拆分为 settingsStore
5. **缺少数据统计页**：无法查看听歌统计、最常听歌手等
6. **缺少均衡器页**：无法调节音频频段
7. **缺少独立动画样式文件**：动画全部在 index.css 中，未拆分为 animations.css

## 2. 设计风格规范（基于参考图片）

### 2.1 色彩方案

| 颜色类型 | 色值 | 用途 |
|----------|------|------|
| 主背景色 | `#f0fdf4` ~ `#dcfce7` | 页面主背景，浅绿色渐变 |
| 卡片背景 | `rgba(255, 255, 255, 0.6)` ~ `rgba(255, 255, 255, 0.8)` | 卡片、弹窗等容器 |
| 强调色 | `#4ade80` ~ `#22c55e` | 按钮、图标、高亮文字 |
| 次强调色 | `#fb923c` ~ `#f97316` | 播放控制、进度条 |
| 文字主色 | `#1f2937` | 标题、主要文字 |
| 文字次要色 | `#6b7280` | 辅助信息、描述文字 |
| 边框/分割线 | `rgba(167, 243, 208, 0.5)` | 柔和的绿色边框 |

### 2.2 渐变背景

```css
/* 主背景渐变 */
background: linear-gradient(180deg, 
  #f0fdf4 0%, 
  #dcfce7 30%, 
  #bbf7d0 60%, 
  #86efac 100%
);

/* 卡片背景渐变 */
background: linear-gradient(135deg, 
  rgba(255, 255, 255, 0.8) 0%, 
  rgba(255, 255, 255, 0.4) 100%
);
```

### 2.3 装饰元素

| 元素 | 样式 | 位置 |
|------|------|------|
| 蝴蝶 | SVG 图标，半透明 | 页面角落、卡片边缘 |
| 树叶 | SVG 图标，半透明 | 顶部、底部边缘 |
| 苹果 | SVG 图标，半透明 | 底部区域装饰 |
| 花朵 | SVG 图标，半透明 | 底部边缘装饰 |

### 2.4 字体风格

- **标题**：粗体，较大字号，自然圆润
- **正文**：常规字重，清晰可读
- **辅助文字**：较小字号，柔和颜色

### 2.5 卡片设计

- **圆角**：`16px ~ 20px`
- **阴影**：柔和投影 `rgba(34, 197, 94, 0.1) 0 4px 20px`
- **边框**：`1px solid rgba(167, 243, 208, 0.3)`
- **内边距**：`16px ~ 20px`

## 3. 动态效果规范

### 3.1 全局动效

| 动效类型 | 描述 | 时长 |
|----------|------|------|
| 页面切换 | fadeIn + slideUp | 300ms |
| 卡片进入 | scaleIn + fadeIn | 200ms |
| 按钮悬停 | scale + 颜色变化 | 150ms |
| 列表滚动 | 平滑滚动 | 默认 |

### 3.2 装饰动画

| 元素 | 动画类型 | 描述 |
|------|----------|------|
| 蝴蝶 | 飞舞动画 | 随机位置飘动，上下起伏 |
| 树叶 | 飘落动画 | 缓慢飘落，轻微旋转 |
| 气泡 | 上浮动画 | 从底部缓慢上升并消失 |
| 背景 | 呼吸动画 | 背景颜色缓慢渐变循环 |

### 3.3 交互反馈

| 交互 | 反馈效果 |
|------|----------|
| 点击按钮 | 缩放回弹 + 波纹效果 |
| 收藏歌曲 | 爱心飞出 + 粒子特效 |
| 播放音乐 | 声波可视化动画 |
| 悬停卡片 | 阴影加深 + 轻微上浮 |

### 3.4 动画实现

```typescript
// 蝴蝶飞舞动画
@keyframes butterflyFly {
  0%, 100% {
    transform: translate(0, 0) rotate(0deg);
  }
  25% {
    transform: translate(20px, -15px) rotate(5deg);
  }
  50% {
    transform: translate(40px, 5px) rotate(-3deg);
  }
  75% {
    transform: translate(20px, 10px) rotate(2deg);
  }
}

// 树叶飘落动画
@keyframes leafFall {
  0% {
    transform: translateY(-100px) rotate(0deg) translateX(0);
    opacity: 0;
  }
  10% {
    opacity: 1;
  }
  100% {
    transform: translateY(100vh) rotate(360deg) translateX(100px);
    opacity: 0;
  }
}

// 呼吸背景动画
@keyframes breathing {
  0%, 100% {
    filter: brightness(1);
  }
  50% {
    filter: brightness(1.05);
  }
}
```

## 9. 风险与注意事项

### 9.1 路由切换时音频不中断

- Audio 实例在 `useAudioPlayer` 中通过 `useRef` 持有，与组件生命周期无关
- 路由切换时 Layout 组件不卸载，Audio 实例保持不变
- 迷你播放器从 Store 读取播放状态，与主页播放器共享同一状态

### 9.2 主页布局兼容

- 主页（`/`）保持现有的左右分栏布局，不使用 Layout 的顶部导航
- 通过路由判断：主页渲染完整播放器，子页面渲染 Layout + 迷你播放器
- 需要确保主页和子页面切换时 CSS 不冲突

### 9.3 移动端适配

- 所有新页面需要适配移动端（<768px）
- 设置页使用全宽卡片布局
- 歌单详情页歌曲列表与现有 SongRow 复用
- 歌曲详情页封面居中，歌词可滚动
- 迷你播放器固定底部，高度 56px

### 9.4 数据持久化

- 设置项全部持久化到 localStorage
- 播放计数持久化到 localStorage（`music_play_counts`）
- 均衡器预设持久化到 localStorage（`music_eq_presets`）
- 导出数据格式为 JSON，包含收藏、历史、歌单、设置、播放计数

### 9.5 性能考虑

- 歌曲详情页的歌词全文使用虚拟滚动（歌曲过长时）
- 数据统计页的计算在 Store 中完成，组件只做展示
- 均衡器的 Web Audio API 处理在 `useAudioPlayer` 中完成，避免重复创建 AudioContext
- 路由切换使用 React.lazy + Suspense 懒加载新页面
- 装饰动画使用 CSS 动画，避免 JavaScript 性能开销

### 9.6 动画性能优化

- 使用 `will-change` 提示浏览器优化动画
- 动画元素使用 `transform` 和 `opacity` 避免重排
- 装饰元素使用 `pointer-events: none` 不干扰交互
- 蝴蝶数量限制在 6 个以内，避免过度动画

- **浅色模式**：浅绿色渐变背景（#f0fdf4 ~ #dcfce7），半透明白色卡片，绿色强调色（#4ade80）
