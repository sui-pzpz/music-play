## 第一部分：接口开发概述

### 1.1 接口架构

```
客户端请求 → Controller → Service → Repository → 数据库
                ↓
            参数校验
                ↓
            业务逻辑
                ↓
            返回响应
```

### 1.2 接口规范

#### 1.2.1 URL规范

- 客户端API前缀：`/api/v1`
- 管理平台API前缀：`/api/v1/admin`
- 使用小写字母，单词用连字符分隔
- 使用名词复数形式（如 `/users` 而非 `/user`）

#### 1.2.2 请求方法

| 方法 | 用途 | 示例 |
|------|------|------|
| GET | 获取资源 | 获取用户信息、歌曲列表 |
| POST | 创建资源 | 用户注册、创建歌单 |
| PUT | 更新资源 | 更新用户信息、编辑歌曲 |
| DELETE | 删除资源 | 删除歌单、取消收藏 |

#### 1.2.3 响应格式

统一使用 `R<T>` 类封装响应：

```java
{
    "code": 200,        // 状态码：200成功，4xx客户端错误，5xx服务端错误
    "message": "success", // 提示信息
    "data": {}          // 业务数据
}
```

#### 1.2.4 认证方式

- 使用 JWT Token
- 通过 `Authorization: Bearer <token>` 请求头传递
- Token 有效期 2 小时
- 登录接口返回 `accessToken` 和 `expiresIn`

## 第二部分：接口开发步骤

### 2.1 开发流程

```
1. 创建实体类 (Entity)
      ↓
2. 创建数据访问层 (Repository)
      ↓
3. 创建数据传输对象 (DTO/VO)

      ↓
5. 创建控制器 (Controller)
      ↓
6. 编写单元测试
      ↓
7. 接口文档更新
```

```java
package com.xx.music.repository;

import com.xx.music.model.entity.User;
import org.springframework.data.domain.Page;
import org.springframework.data.domain.Pageable;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.stereotype.Repository;

import java.time.LocalDateTime;
import java.util.Optional;

@Repository
public interface UserRepository extends JpaRepository<User, Long> {

    Optional<User> findByUidAndDeletedAtIsNull(String uid);

    Optional<User> findByPhoneAndDeletedAtIsNull(String phone);

    long countByDeletedAtIsNull();

    long countByDeletedAtIsNullAndStatus(Integer status);

    long countByCreatedAtAfterAndDeletedAtIsNull(LocalDateTime createdAt);

    Page<User> findByStatusAndDeletedAtIsNull(Integer status, Pageable pageable);
```

**示例**：用户服务实现

```java
package com.xx.music.service.impl;

import com.xx.music.model.dto.RegisterDTO;
import com.xx.music.model.entity.User;
import com.xx.music.repository.UserRepository;
import com.xx.music.service.UserService;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;

@Service
@RequiredArgsConstructor
public class UserServiceImpl implements UserService {

    private final UserRepository userRepository;

    @Override
    public UserVO register(RegisterDTO dto) {
        // 1. 检查手机号是否已注册
        User existing = userRepository.findByPhone(dto.getPhone());
        if (existing != null) {
            throw new BusinessException(400, "手机号已注册");
        }

        // 2. 生成用户UID
        String uid = generateUid();

        // 3. 加密密码
        String encodedPassword = passwordEncoder.encode(dto.getPassword());

        // 4. 创建用户
        User user = new User();
        user.setUid(uid);
        user.setPhone(dto.getPhone());
        user.setPassword(encodedPassword);
        user.setNickname(dto.getNickname() != null ? dto.getNickname() : "用户" + uid);

        userRepository.insert(user);

        // 5. 生成Token并返回
        String token = jwtTokenProvider.generateToken(uid);
        return buildUserVO(user, token);
    }

    // ... 其他方法实现
}
```

## 第三部分：各模块接口实现

### 3.1 用户认证模块

#### 3.1.1 用户注册

**接口**：`POST /api/v1/auth/register`

**实现步骤**：

1. **参数校验**：验证手机号格式、密码强度
2. **业务校验**：检查手机号是否已注册
3. **数据处理**：加密密码、生成用户UID
4. **数据存储**：保存用户信息到数据库
5. **生成Token**：创建JWT Token
6. **返回响应**：返回用户信息和Token

**代码实现**：

```java
@PostMapping("/register")
public R<AuthVO> register(@Valid @RequestBody RegisterDTO dto) {
    AuthVO auth = authService.register(dto);
    return R.ok(auth);
}
```

#### 3.1.2 用户登录

**接口**：`POST /api/v1/auth/login`

**实现步骤**：

1. **参数校验**：验证手机号和密码
2. **用户查询**：根据手机号查找用户
3. **密码验证**：使用BCrypt验证密码
4. **登录失败处理**：记录失败次数，超过5次锁定30分钟
5. **生成Token**：创建JWT Token
6. **更新登录信息**：记录最后登录时间和IP
7. **返回响应**：返回用户信息和Token

**代码实现**：

```java
@PostMapping("/login")
public R<AuthVO> login(@Valid @RequestBody LoginDTO dto, 
                       HttpServletRequest request) {
    String ip = getClientIp(request);
    AuthVO auth = authService.login(dto, ip);
    return R.ok(auth);
}
```

#### 3.1.3 刷新Token

**接口**：`POST /api/v1/auth/refresh`

**实现步骤**：

1. **验证RefreshToken**：检查Token有效性和过期时间
2. **生成新Token**：创建新的AccessToken
3. **返回响应**：返回新Token和过期时间

**代码实现**：

```java
@PostMapping("/refresh")
```

## 第六部分：开发注意事项

### 6.1 安全注意事项

1. **密码安全**：使用BCrypt加密存储，不要明文存储
2. **SQL注入**：使用参数化查询，不要拼接SQL
3. **XSS攻击**：对用户输入进行转义处理
4. **CSRF攻击**：使用Token验证
5. **敏感信息**：手机号、密码等敏感信息需要加密

### 6.2 性能注意事项

1. **数据库查询**：添加必要的索引，避免全表扫描
2. **缓存使用**：合理使用Redis缓存热点数据
3. **分页查询**：避免一次性加载大量数据
4. **连接池**：合理配置数据库连接池
5. **异步处理**：耗时操作使用异步处理

### 6.3 代码规范

1. **命名规范**：遵循项目命名规范文档

4. **日志记录**：记录关键操作日志

### 6.4 测试注意事项

1. **测试覆盖**：保证关键业务逻辑的测试覆盖

```java
package com.xx.music.common;

import lombok.Data;

@Data
public class R<T> {
    private int code;

        r.code = 200;

        return r;
    }

    public static <T> R<T> fail(int code, String message) {

        r.message = message;
        return r;
    }
}
```

```java
package com.xx.music.common;

import lombok.extern.slf4j.Slf4j;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public R<Void> handleBusinessException(BusinessException e) {
        log.warn("业务异常: {}", e.getMessage());
        return R.fail(e.getCode(), e.getMessage());

    }
}
```
