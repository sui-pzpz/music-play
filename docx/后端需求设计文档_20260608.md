## 一、技术架构
### 1.1 整体架构
```
客户端(Web/PC) → CDN → Nginx → Spring Boot 单体应用
                                  ├── config/          # 配置类
                                  ├── controller/      # 控制器层
                                  │   ├── admin/       # 管理员控制器
                                  │   ├── auth/        # 认证控制器
                                  │   ├── user/        # 用户控制器
                                  │   ├── song/        # 歌曲控制器
                                  │   ├── playlist/    # 歌单控制器
                                  │   ├── search/      # 搜索控制器
                                  │   ├── recommend/   # 推荐控制器
                                  │   ├── member/      # 会员控制器
                                  │   ├── file/        # 文件控制器
                                  │   └── notify/      # 通知控制器
                                  ├── service/         # 服务层
                                  ├── repository/      # 数据访问层
                                  ├── model/           # 实体模型
                                  ├── security/        # 安全/鉴权
                                  └── common/          # 公共工具类
                              → Redis缓存
                              → MySQL数据库
                              → OSS/CDN
```

### 1.2 技术选型
| 组件 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 框架 | Spring Boot | 3.x | 单体架构，RESTful API |
| 数据库 | MySQL | 8.0 | 核心业务数据存储 |
| 缓存 | Redis | 7.x | 热点数据缓存 |
| 构建工具 | Maven | - | 依赖管理 |
| 文件存储 | OSS + CDN | - | 音视频、图片、歌词 |
| 部署 | Docker | latest | 容器化部署 |

### 1.3 模块划分
| 模块 | 职责 | 说明 |
|------|------|------|
| config | 配置类 | 全局配置管理 |
| controller/admin | 管理员控制器 | 管理平台接口 |
| controller/auth | 认证控制器 | 用户注册/登录/鉴权 |
| controller/user | 用户控制器 | 用户信息管理 |
| controller/song | 歌曲控制器 | 歌曲元数据/播放/歌词 |
| controller/playlist | 歌单控制器 | 歌单CRUD |
| controller/search | 搜索控制器 | 搜索功能 |
| controller/recommend | 推荐控制器 | 推荐列表 |
| controller/member | 会员控制器 | 会员/订阅/付费 |
| controller/file | 文件控制器 | 文件上传/下载 |
| controller/notify | 通知控制器 | 消息通知 |

## 二、核心数据模型
### 2.1 用户表（t_user）
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 用户ID |
| username | VARCHAR(64) | NOT NULL, UNIQUE | 用户名 |
| email | VARCHAR(128) | UNIQUE | 邮箱 |
| phone | VARCHAR(16) | UNIQUE | 手机号 |
| password_hash | VARCHAR(256) | NOT NULL | 密码哈希 |
| avatar | VARCHAR(256) | - | 头像URL |
| nickname | VARCHAR(64) | - | 昵称 |
| status | TINYINT | DEFAULT 1 | 状态(0禁用/1启用) |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

### 2.2 音乐表（t_song）
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 音乐ID |
| title | VARCHAR(256) | NOT NULL | 歌曲名 |
| duration | INT | NOT NULL | 时长(秒) |
| album_id | BIGINT | FOREIGN KEY | 专辑ID |
| cover_url | VARCHAR(512) | - | 封面URL |
| audio_url | VARCHAR(512) | - | 音频URL |
| lyric_url | VARCHAR(512) | - | 歌词URL |
| quality | VARCHAR(16) | DEFAULT 'standard' | 音质 |
| plays_count | BIGINT | DEFAULT 0 | 播放次数 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 2.3 歌单表（t_playlist）
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 歌单ID |
| user_id | BIGINT | FOREIGN KEY, NOT NULL | 创建者ID |
| name | VARCHAR(128) | NOT NULL | 歌单名称 |
| description | TEXT | - | 描述 |
| cover_url | VARCHAR(512) | - | 封面URL |
| is_public | TINYINT | DEFAULT 1 | 是否公开 |
| song_count | INT | DEFAULT 0 | 歌曲数量 |
| plays_count | BIGINT | DEFAULT 0 | 播放次数 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

### 2.4 用户收藏表（t_favorite）
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | ID |
| user_id | BIGINT | FOREIGN KEY, NOT NULL | 用户ID |
| song_id | BIGINT | FOREIGN KEY, NOT NULL | 歌曲ID |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

## 四、数据安全
### 4.1 认证机制
- JWT Token：无状态认证，Token有效期2小时
- 密码安全：使用BCrypt哈希算法
- 短信验证码：有效期5分钟，最多发送3次/分钟

### 4.2 权限控制
- 基于角色的访问控制（RBAC）
- 接口限流：单用户每分钟最多请求100次

### 4.3 数据加密
- 敏感数据脱敏存储
- 传输层使用HTTPS
