## 第一部分：管理平台概述

### 1.1 平台定位

管理平台是面向运营人员的后台管理系统，提供以下核心能力：

- **用户管理**：查看、搜索、启用/禁用、删除用户，查看用户播放历史和收藏
- **歌曲管理**：查看、搜索、新增、编辑、上架/下架、删除歌曲
- **数据概览**：首页仪表盘展示平台核心统计数据
- **操作日志**：记录和追溯所有管理员操作

### 1.2 技术选型

| 层级 | 技术 | 说明 |
| --- | --- | --- |
| **后端框架** | Spring Boot 3.x + Java 17 | 与主项目一致 |
| **ORM** | Spring Data JPA | 与主项目一致 |
| **鉴权** | JWT（JJWT）+ BCrypt | 管理员使用独立 Token，subject 前缀 `admin:` |
| **数据库** | MySQL 8.0+ | 使用 `t_admin` 和 `t_admin_log` 两张表 |
| **前端框架** | Vue 3 + TypeScript + Element Plus | 已实现，独立后台管理模板 |
| **前端状态管理** | Pinia | Vue 3 官方推荐 |
| **前端路由** | Vue Router 4 | SPA 路由，history 模式 |
| **前端 HTTP** | Axios | 封装 API 请求，带 Token 拦截器 |
| **前端构建** | Vite | 快速开发构建 |
| **前端部署** | 静态资源放置于 `backend/src/main/resources/static/admin/` | Spring Boot 直接托管 |

### 1.3 权限角色

| 角色 | 权限范围 |
| --- | --- |
| **super_admin** | 全部权限：用户管理（含禁用/删除）、歌曲管理（含新增/编辑/下架/删除）、查看操作日志、管理其他管理员 |
| **admin** | 受限权限：查看用户列表、查看歌曲列表、编辑歌曲信息、下架歌曲 |

> 当前代码中权限控制尚未完全实现，多数接口未做角色校验。

### 2.2 模块一：管理员认证

**功能描述**：提供管理员的登录、登出、获取当前用户信息的功能。

**涉及表**：`t_admin`

**核心逻辑**：
- 管理员登录时，使用 BCrypt 验证密码
- 检查账号状态（status=1 为正常，0 为禁用）
- 登录成功后更新 `last_login_at` 和 `last_login_ip`
- 生成 JWT Token，subject 格式为 `admin:{id}`（如 `admin:1`）
- Token 有效期 2 小时

**当前实现状态**：
- `POST /api/v1/admin/login` — 已实现
- `POST /api/v1/admin/logout` — 空实现（仅返回成功，JWT 无状态无需额外处理）
- `GET /api/v1/admin/profile` — 已实现
- `GET /api/v1/admin/dashboard` — 已实现（仪表盘，归属此 Controller）

**已修复问题**（V2.0）：
- `AdminAuthVO` 字段已统一为 `token`，删除了对不存在的 `avatar` 字段的调用

### 2.3 模块二：数据概览

**功能描述**：管理平台首页仪表盘，展示平台核心运营数据。

**涉及表**：`t_user`、`t_song`、`t_playlist`、`t_play_history`

**统计指标**：

| 指标 | 说明 | 数据来源 |
| --- | --- | --- |
| 总用户数 | 未删除的用户总数 | `t_user` WHERE deleted_at IS NULL |
| 今日新增用户 | 今日注册的用户数 | `t_user` WHERE created_at >= 今日 00:00 |
| 总歌曲数 | 所有歌曲数量 | `t_song` COUNT |
| 上架歌曲数 | status=1 的歌曲数 | `t_song` WHERE status=1 |
| 总歌单数 | 未删除的歌单数 | `t_playlist` WHERE deleted_at IS NULL |
| 今日播放次数 | 今日播放记录数 | `t_play_history` WHERE played_at >= 今日 00:00 |

**当前实现状态**：
- `GET /api/v1/admin/dashboard` — 已实现（Service 层 + Controller 层）
- 仪表盘返回扁平结构：`totalUsers`、`todayNewUsers`、`totalSongs`、`activeSongs`、`totalPlaylists`、`todayPlayCount`
- 最近操作记录（`recentActions`）已实现，查询最近 10 条操作日志并关联管理员用户名

**已修复问题**（V2.0）：
- `AdminDashboardVO` 已改为扁平结构 + `RecentAction` 内部类，与 Service 填充逻辑一致
- 仪表盘已增加"最近操作记录"功能

## 第五部分：接口详细文档

### 5.1 接口前缀与认证

- 接口前缀：`/api/v1/admin`
- 认证方式：JWT Token，通过 `Authorization: Bearer <token>` 请求头传递
- 通用响应格式：`{"code": 200, "data": {...}, "message": "success"}`

### 5.2 接口清单

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| POST | `/api/v1/admin/login` | 管理员登录 | 无需认证 |
| POST | `/api/v1/admin/logout` | 管理员登出 | 需认证 |
| GET | `/api/v1/admin/profile` | 获取当前管理员信息 | 需认证 |
| GET | `/api/v1/admin/dashboard` | 数据概览 | 需认证 |
| GET | `/api/v1/admin/users` | 用户列表 | 需认证 |
| GET | `/api/v1/admin/users/{uid}` | 用户详情 | 需认证 |
| PUT | `/api/v1/admin/users/{uid}` | 编辑用户信息 | 需认证 |
| PUT | `/api/v1/admin/users/{uid}/status` | 启用/禁用用户 | super_admin |
| DELETE | `/api/v1/admin/users/{uid}` | 删除用户 | super_admin |
| GET | `/api/v1/admin/users/{uid}/history` | 用户播放历史 | 需认证 |
| GET | `/api/v1/admin/users/{uid}/favorites` | 用户收藏列表 | 需认证 |
| GET | `/api/v1/admin/songs` | 歌曲列表 | 需认证 |
| GET | `/api/v1/admin/songs/{songId}` | 歌曲详情 | 需认证 |
| POST | `/api/v1/admin/songs` | 新增歌曲 | super_admin |
| PUT | `/api/v1/admin/songs/{songId}` | 编辑歌曲 | 需认证 |
| PUT | `/api/v1/admin/songs/{songId}/status` | 上架/下架歌曲 | 需认证 |
| DELETE | `/api/v1/admin/songs/{songId}` | 删除歌曲 | super_admin |
| GET | `/api/v1/admin/logs` | 操作日志列表 | 需认证 |

### 5.3 错误码约定

| 状态码 | 说明 |
| --- | --- |
| 200 | 成功 |
| 400 | 参数校验失败 |
| 401 | 未认证（Token 无效或过期） |
| 403 | 无权限（角色不足） |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

> 业务错误通过 `R` 的 `code` 字段区分，HTTP 状态码统一为 200。
